## プロジェクト概要

- **メインプロジェクト**: **rowke（ローク）** — 子どもの“成長の航跡”を見つけるアート教室アプリ
  - プロダクトURL: https://art-feedback.vercel.app
  - 第1回からずっと育ててきた本命。第9回もこの rowke を進化させて発表する。
- **派生プロジェクト**: **Wake Path（ウェイクパス）** — rowke から派生した、**中高生向け・受験デッサン特化**のトレーニング版
  - プロダクトURL: https://wake-path.vercel.app
  - 第8回の検証で出た「受験特化・毎日描ける版が欲しい」という声に応えて派生開発。rowke から導線でつなぐ。
- **テーマ**: 先生が常にいなくても、子ども・生徒が描き続け、AIが採点・対話しながら成長を支える

第8回（rowke v4）の価値検証で得た「最大の気づき」を、**実際に使ってもらうための具体的な改善**に翻訳し、rowke を v5 として進化させた（その一環として派生版 Wake Path への導線を新設）。

## 第8回インタビューの最大の気づき（出発点）

協力者（美術系受験を目指す一般ユーザー）の声で最も大きかったのは：

> **「成長の軌跡を振り返れることが継続の決め手。ただし“受験デッサンに特化して、毎日描ける版”が欲しい」**

= 汎用の rowke は「週1の総合アート教室」。**毎日描く受験層には、特化・高頻度の体験が必要**だと判明。これを v5 の指針にした。

---

## v4 → v5 で変えたこと（声 → 具体的な変更）

インタビューの声を、1つの「これを直したら使われそう」な具体的変更に絞って反映した。

### 変更：rowke から「受験デッサン特化版 Wake Path」への導線を新設
- 第8回の声「受験に特化して、毎日描ける版が欲しい」に対し、**rowke本体を肥大化させるのではなく**、その用途に専念した派生版 **Wake Path（中高生向けデッサン特化）** を別途開発。
- rowke のホームに「**受験生・毎日描きたい人へ → Wake Path**」の導線（CTAカード）を新設し、ワンタップで送れるように。
- → rowke（汎用・週1の総合アート教室）と Wake Path（受験特化・毎日トレーニング）を**用途で切り分け**、それぞれの体験を最適化。
- 導線先 URL：https://wake-path.vercel.app

### 導線先 Wake Path の主な特徴（派生開発で実装したもの）
- ⏱ **スリープに強いタイマー**（終了時刻ベース＋画面スリープ抑止）で、毎日の制限時間練習が現実的に回る
- 🎯 **志望校レベル別の合格ライン**＋AIの9軸採点を受験基準でキャリブレーション
- 🌊 **海底→水面（合格）へ浮上する成長の航跡** ／ 🏴‍☠️ 10段階の航海バッジ
- 📝 **自分のふりかえりメモ**（音声入力対応） ／ 🧭 “問いで気づかせる”厳格な Wake先生

## 価値検証の考え方

- 「受験・毎日描きたい」というニーズに、汎用アプリを無理に拡張せず、**専用版へ導線で橋渡し**する形で応えた。
- これにより rowke は「間口の広い入口」、Wake Path は「受験を本気できわめる場」として役割が明確になった。

## 次のステップ（最終発表 7/16 に向けて）

最終的には、本命である **rowke（https://art-feedback.vercel.app）** を、Wake Path の開発・検証で得た知見を統合した**進化版**として発表する。
※ Wake Path は今後も**少人数（個別利用）**のまま運用するためスケール対応はしない。スケール設計は**発表する rowke 側**に集中する。

1. **rowke を同時 30〜300人でも耐えるスケーラブル設計へ**
   - 画像をDB直書きから**ストレージ（URL参照）方式**へ移行し、全件読み込みをやめて**生徒単位・ページング読み込み**に
   - AI採点の**レート制御・キャッシュ・コスト上限**を設定
   - 閲覧/編集の**権限分離（アクセス制御）**
2. **AIの質を担保**
   - AI採点の一貫性チェック（AI vs 先生の一致度）／お手本作品による較正
3. **作品展示（ギャラリー・講評）の進化**
   - 講評の作品展示部分をより魅力的に。テーマ別・成長順の見せ方、作品を主役にした展示レイアウト、講評会の体験を強化
4. **頑張りへのご褒美：Rowkeコイン → グッズ**
   - 取り組みに応じて **Rowkeコイン**を発行（継続のモチベーションに）
   - 一定数貯まったら、**その子の絵を使ったグッズ**をプレゼント（例：絵をプリントしたアクリルキーホルダー・トートバッグ／絵を刺繍した帽子）
5. **運用テスト → 7/16 ライブデモ整備**
   - 実際の受験生・子どもに使ってもらい「継続して使われるか」を再検証
   - 志望校レベル別の合格ライン判定の精度チェック（過去作と照合）

## 使用技術
- フロントエンド: HTML / CSS / Vanilla JS（単一ファイル構成）
- AI: Google Gemini 2.5 Flash（画像採点・対話）／ Claude Code（実装）
- DB: Firebase（rowke-app プロジェクト。書き込みはサーバーAPI経由＋先生PIN照合）
- 端末機能: Web Speech API（音声入力）／ Screen Wake Lock API（スリープ抑止）
- ホスティング: Vercel
