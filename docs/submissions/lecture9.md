## プロジェクト概要

- **プロジェクト名**: Wake Path（ウェイクパス）
- **位置づけ**: rowke（アート教室アプリ）から派生した、**受験デッサンの経過観察＆毎日トレーニングに特化**した版
- **プロダクトURL**: https://wake-path.vercel.app
- **テーマ**: 先生が常にいなくても、生徒が毎日デッサンを積み上げ、AIが採点・対話しながら合格まで導く

第8回（rowke v4）の価値検証で得た「最大の気づき」を、**実際に使ってもらうための具体的な改善**に翻訳し、v5 として進化させた。

## 第8回インタビューの最大の気づき（出発点）

協力者（美術系受験を目指す一般ユーザー）の声で最も大きかったのは：

> **「成長の軌跡を振り返れることが継続の決め手。ただし“受験デッサンに特化して、毎日描ける版”が欲しい」**

= 汎用の rowke は「週1の総合アート教室」。**毎日描く受験層には、特化・高頻度の体験が必要**だと判明。これを v5 の指針にした。

---

## v4 → v5 で変えたこと（声 → 具体的な変更）

インタビューの声を、1〜2個の「これを直したら使われそう」な変更に絞って反映した。

### ① 「毎日描きたい」→ タイマーをスリープに強く改修
- 課題には**制限時間**があるが、スマホは紙に描いている間に画面が消え、従来のタイマーは止まってしまっていた。
- **終了時刻（タイムスタンプ）ベースに作り直し**、画面オフ・スリープ・バックグラウンドでも実時間で正確に計測。さらに **画面スリープ抑止（Screen Wake Lock）** を追加。
- → 毎日の制限時間練習が、現実的に回るようになった。

### ② 「受験に特化して正確に見てほしい」→ 志望校レベル別の合格ライン
- 生徒（志望校）ごとに **合格ライン（総合・5点満点）** を設定可能に。
- その値に応じて **AIの9軸採点を受験基準でキャリブレーション**し、「合格まであと何が必要か」をその子の志望校基準で判定。

### （+α）この期に行った主な改善（開発の経緯）
- 📝 添削を受けての気づきを残す **「自分のふりかえり」メモ**（音声入力対応）
- 🧭 Wake先生の人格を **“答えを言わず問いで気づかせる厳格な師匠”** に再設計（安易に褒めない／時間をかけて考えさせる）
- 🌊 成長の記録を **「海底（スタート）→水面（合格）へ浮上する航跡」** ビジュアルに刷新
- 🏴‍☠️ 達成度を示す **10段階の航海バッジ**（獲得時に泡が立ちのぼる演出）

## 次のステップ（最終発表 7/16 に向けて）

最終的には、本命である **rowke（https://art-feedback.vercel.app）** を、Wake Path の開発・検証で得た知見を統合した**進化版**として発表する。
※ Wake Path は今後も**少人数（個別利用）**のまま運用するためスケール対応はしない。スケール設計は**発表する rowke 側**に集中する。

1. **Wake Path の成果を rowke 本体へ統合**
   - 受験デッサン特化モード／「海底→水面（合格）へ浮上する成長の航跡」可視化／“問いで気づかせる”厳格な Wake先生／自分のふりかえり／スリープに強いタイマー を取り込む
2. **rowke を同時 30〜300人でも耐えるスケーラブル設計へ**
   - 画像をDB直書きから**ストレージ（URL参照）方式**へ移行し、全件読み込みをやめて**生徒単位・ページング読み込み**に
   - AI採点の**レート制御・キャッシュ・コスト上限**を設定
   - 閲覧/編集の**権限分離（アクセス制御）**
3. **AIの質を担保**
   - AI採点の一貫性チェック（AI vs 先生の一致度）／お手本作品による較正
4. **運用テスト → 7/16 ライブデモ整備**
   - 実際の受験生に毎日使ってもらい「継続して使われるか」を再検証
   - 志望校レベル別の合格ライン判定の精度チェック（過去作と照合）

## 使用技術
- フロントエンド: HTML / CSS / Vanilla JS（単一ファイル構成）
- AI: Google Gemini 2.5 Flash（画像採点・対話）／ Claude Code（実装）
- DB: Firebase（rowke-app プロジェクト。書き込みはサーバーAPI経由＋先生PIN照合）
- 端末機能: Web Speech API（音声入力）／ Screen Wake Lock API（スリープ抑止）
- ホスティング: Vercel
