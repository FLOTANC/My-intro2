02 — MAIN EVENT

👾 銀河特急を止めろ！

導入アナウンス：「銀河特急MILKY-06が制御不能になった。18:00までに3つのミッションでアクセスコードを集め、非常ブレーキを起動せよ。」家の中に3ステーションを設置する。ここで集めたコードが、15:00からのプラレール急停車ゲームの前提になる。

01

SHIELD DEFENSE

撃ち手がナーフ銃を構え、参加者は盾を持って弾を止める。1人10発、止められた数がそのままポイント。盾の大きさで年齢差を調整でき、幼児は距離を近づけて大きい盾にすれば同じルールで参加できる。

02

ALIEN HUNT

家の中に小さな宇宙人・ロボットカードを隠す「逃亡ロボットを回収せよ」。幼児組も活躍できる担当。

03

SYSTEM HACK

中学生＋小学生向け。暗号を解いて最後のパスワードを導く。端末はiPadまたはPCで /hack を開く。4桁を入力し、間違えると警報とともに ACCESS DENIED、正解すると UNLOCKED。ここまでが前半戦。

ACCESS CODE
2 0 2 6

01で「2」、02で「0・2」、03の暗号で最後の「6」。入力に成功したら「BRAKE SYSTEM UNLOCKED／ただし列車はまだ走行中」とアナウンスし、そのまま15:00の急停車ゲームへ引き継ぐ。

03 — FINAL GAME

🚄 EMERGENCY STOP／プラレール急停車

プラレールで銀河特急を走らせ、ぐにゃぐにゃボールを当てて急停車させるゲーム。廊下に直線レールを長く敷き、レール脇に「非常停止スイッチ」を立てる。列車そのものを狙うのではなくスイッチを倒す形にすると、車両が壊れず、成功／失敗も一目でわかる。

RULE

非常停止スイッチを倒す

レール脇に紙コップを3個立て、これを「BRAKE 01 / 02 / 03」とする。列車が通過し切る前にボールを当てて倒す。1人3投。全部倒せば EMERGENCY STOP 成立で、大人がその場で電源を切る。

PENALTY

車両に直撃＝脱線

列車本体に当ててしまったら「銀河特急を破壊した」で得点なし。狙って外す精度が要るので、小6・中3でも簡単すぎない。ぐにゃぐにゃボールなら当たっても車両は傷まない。

LEVEL

年齢差の調整

投げる位置を年齢別ラインで分ける。2歳・3歳はレールのすぐ横から。難度はスピード設定と、コップまでの距離で変えられる。中3にはトンネルや坂を足して、見えない区間を挟むと一気に難しくなる。

ROLE

2歳は「発車係」

プラレールは2歳が一番触りたがるので、最初から発車ボタン担当にしてしまう。「MILKY-06、発車！」の合図役にすると、待ち時間も自分の出番になる。

ROUND

2ラウンド制

15:00に予選（全員1巡）、16:30に決勝。決勝はスピードを上げる、コップを2個に減らす、車両を1両にして的を小さくする、のいずれかで難度を上げる。

SET

用意するもの

プラレールの直線レールをできるだけ長く、紙コップ、ぐにゃぐにゃボール5個。車体は黒い紙とネオンテープを巻いて「MILKY-06」に改装。レールの先に「PLATFORM 06」の紙を置けば終着駅になる。

ANNOUNCE
EMERGENCY BRAKE ACTIVATED

紙コップが全部倒れたら、大人がその場でプラレールの電源を切る。同時に照明を落として緑のライトに切り替え、「銀河特急、停止成功」とアナウンス。02で集めたコードがここで効いた、という形で一日が完結する。

04 — PRIZE

🎁 景品の配り方

ストレス発散輪が1個しかないので、「一番強い子が総取り」にならない設計にしておくと最後まで全員が動く。

ALL CREW

スクイーズ（全員）

17:40の表彰で、乗車PASSのスタンプが全部埋まった証として全員に配る。順位ではなく「完走賞」の位置づけ。

EQUIPMENT

ぐにゃぐにゃボール（5個）

景品にせず、プラレール急停車ゲームの弾として一日中使う。5個あれば1人3投のローテーションが途切れない。最後にじゃんけんやくじで持ち帰り担当を決めると、それ自体がもう一つのイベントになる。

MVP × 1

ストレス発散輪

1個しかないので、実力の合計点ではなく「くじ」か「幼児でも取れる賞」で渡すのが安全。案は右記の3通り。

A

RANDOM ITEM BOX

ミッションと急停車ゲームで1回成功するごとに抽選券を1枚。最後に箱から1枚引く。多く頑張った子ほど当たりやすいが、発車係の2歳にもチャンスが残る。

B

部門賞にする

「最速停止賞」「一番いい叫び声賞」「一番派手に脱線させた賞」など、大人が現場で決める変な賞を作り、その1つの景品にする。中3が笑って納得しやすい。

C

大人チームの賞にする

そもそも子どもに渡さず、大人3人の対決の景品にしてしまう。ストレス発散輪という景品の性格にも合っていて、子どもが観客として盛り上がる。

05 — CREW PASS

🎫 乗車PASSとスタンプ

受付はiPadで行う（/checkin を玄関の端末に開いておく）。名前をタッチするとCREW-01〜09がランダムに割り当てられ、乗車PASS画面と発車ベルが出る。同じアプリの「得点管理」で、各ゲームの点数をCREW番号ごとに記録・集計でき、合計タブで順位が出る。紙のPASSはその番号を書き込んで首から下げる形にし、ミッションと予選をクリアするたびにスタンプ。全員そろったら「MISSION COMPLETE 2026.08」カードを渡し、その場でスクイーズを配る。
